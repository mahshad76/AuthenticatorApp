# AppleNewsApp
Dive into the world of Apple with this Android mobile app. AppleNewsApp lets you seamlessly sign up and log in to access a curated feed of trending Apple articles. Users can instantly like and save any article, building a completely personalized reading list that persists securely even after the app is closed.
